# Мафия — PWA-приложение

Мобильное Progressive Web App для игры «Мафия»: таблица из 10 игроков с выбором ролей и состояний. Данные сохраняются в localStorage.

## Требования

- Node.js 18 или выше

## Установка

```bash
npm install
```

## Запуск

**Режим разработки:**

```bash
npm run dev
```

Откройте в браузере адрес из вывода (обычно http://localhost:5173).

**Сборка:**

```bash
npm run build
```

**Просмотр собранной версии:**

```bash
npm run preview
```

## Установка PWA на телефон

### Android

1. Откройте приложение в Chrome.
2. В меню выберите «Установить приложение» или «Добавить на главный экран».
3. Подтвердите установку.

### iOS (Safari)

1. Откройте приложение в Safari.
2. Нажмите кнопку «Поделиться» (квадрат со стрелкой).
3. Выберите «На экран „Домой“».
4. Подтвердите добавление.

## Участники турнира из Google Таблицы

Список игроков подгружается из [Google Таблицы](https://docs.google.com/spreadsheets/d/1NLKHHpv4zLpLar6qguEFE_Zo9dt2sJDmQrpo4wVB-Vg) (страница «Игроки», колонка A со 2-й строки). При запуске приложения данные загружаются автоматически и сохраняются в localStorage для офлайн-режима. Кнопка «Обновить» в Настройках повторно загружает список.

Таблица должна быть доступна по ссылке («Доступ для всех, у кого есть ссылка»). При ошибке CORS используйте ручное редактирование в Настройках.

## Функции

- Таблица из 10 игроков
- Роли: Мафия, Мирный, Дон, Шериф
- Состояния: В игре, Убит, Заголосован, Удален
- Автосохранение в localStorage
- Тёмная тема
- Mobile-first дизайн
- Работа в офлайн-режиме (PWA)
- **Синхронизация с Google Sheets** — автоматическое обновление имен игроков в таблице по номеру стола

## Синхронизация с Google Sheets

При выборе имени игрока оно автоматически проставляется в Google Sheets на соответствующий лист и позицию.

### Как настроить

1. **Откройте Google Apps Script:**
   - Перейдите на https://script.google.com
   - Создайте новый проект

2. **Скопируйте код:**
   - Скопируйте содержимое файла `scripts/appsScript.gs` в редактор скрипта

3. **Разверните как Web App:**
   - Нажмите **Deploy → New Deployment**
   - Выберите тип: **Web app**
   - **Execute as:** выберите ваш аккаунт
   - **Who has access:** выберите **Anyone**
   - Нажмите **Deploy** и скопируйте URL

4. **Добавьте URL в конфигурацию:**
   - Откройте файл `.env.local` в корне проекта
   - Вставьте скопированный URL:
     ```
     VITE_APPS_SCRIPT_URL=https://script.google.com/macros/d/YOUR_SCRIPT_ID/usercache
     ```

5. **Настройте номер стола:**
   - В Настройках приложения выберите номер стола (1, 2, 3...)
   - Листы в Google Sheets должны называться **Стол1, Стол2, Стол3** и т.д.
   - Игроки должны быть в колонке A, строки 2–11 (A2 для игрока 1)

### Как работает

- При включении опции **Использовать Google Sheets** каждое изменение имени игрока отправляется на Google Apps Script
- Google Apps Script обновляет соответствующий лист таблицы (Стол1, Стол2 и т.д.)
- Имя проставляется в позицию A[номер_игрока + 1]
- Если листа нет, он создается автоматически

### Отключение синхронизации

Если переменная `VITE_APPS_SCRIPT_URL` не заполнена в `.env.local`, синхронизация будет отключена и ошибок не будет.
