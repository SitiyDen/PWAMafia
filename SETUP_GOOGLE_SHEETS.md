# Руководство: Настройка синхронизации с Google Sheets

Это руководство поможет вам настроить автоматическое обновление имен игроков в Google Sheets при выборе в приложении.

## Пошаговая инструкция

### Шаг 1: Откройте Google Apps Script

1. Перейдите на https://script.google.com
2. Нажмите "Новый проект" (или "+")
3. Временно назовите проект (например, "Mafia Sheets Updater")

### Шаг 2: Скопируйте код

1. В редакторе скрипта найдите файл `Code.gs`
2. Удалите весь код по умолчанию
3. Откройте файл `scripts/appsScript.gs` в вашем проекте PWA Mafia
4. Скопируйте весь содержимое файла `appsScript.gs`
5. Вставьте его в `Code.gs` на страницах Google Apps Script

### Шаг 3: Разверните как Web App

1. В меню выберите **Deploy → New Deployment** (иконка закрытого замка на левой панели)
2. Нажмите на кнопку **Create deployment**
3. В поле "Select type" выберите **Web app**
4. Заполните параметры:
   - **Execute as:** выберите ваш Google аккаунт
   - **Who has access:** выберите **Anyone** (или **Anyone with the link** если хотите ограничить)
5. Нажмите **Deploy**
6. Google попросит разрешение на доступ к вашим таблицам. Нажмите **Allow**

### Шаг 4: Скопируйте URL развернутого приложения

1. После успешного развертывания вы получите окно с URL вроде:
   ```
   https://script.google.com/macros/d/YOUR_SCRIPT_ID/usercache
   ```
2. Скопируйте весь это URL

### Шаг 5: Добавьте URL в приложение

1. Откройте файл `.env.local` в корне проекта PWA Mafia:
   ```
   /Users/sitiydenis/Documents/PWAMafia/.env.local
   ```
2. Вставьте скопированный URL:
   ```
   VITE_APPS_SCRIPT_URL=https://script.google.com/macros/d/YOUR_SCRIPT_ID/usercache
   ```
3. Сохраните файл

### Шаг 6: Настройте структуру Google Sheets

Убедитесь, что ваша Google Таблица имеет следующую структуру:

- **Листы:** `Стол1`, `Стол2`, `Стол3` и т.д. (для каждого номера стола)
- **Колонка A:** Имена игроков
- **Строки:**
  - A1: Заголовок (опционально, например "Игрок")
  - A2-A11: Имена игроков (10 слотов)

Пример:
```
| A              |
|----------------|
| Игрок          | (A1 - заголовок)
| Alice          | (A2 - игрок 1)
| Bob            | (A3 - игрок 2)
| Charlie        | (A4 - игрок 3)
| ...            |
| (пусто)        | (A11 - игрок 10)
```

### Шаг 7: Проверьте, что Google Sheets доступна

Убедитесь, что у вас есть доступ к редактированию таблицы. Google Apps Script будет обновлять листы от вашего имени.

### Шаг 8: Перезагрузите приложение

1. Перезагрузите приложение в браузере (Ctrl+R или Cmd+R)
2. Перейдите в Настройки
3. Убедитесь, что:
   - Выбран правильный **Номер стола** (например, 1 для листа "Стол1")
4. На вкладке Игра выберите имя игрока

### Шаг 9: Проверьте результат

После выбора имени игрока:

1. Откройте Google Sheets в браузере
2. Перейдите на лист "Стол1" (или соответствующий номер)
3. Проверьте, что имя появилось в колонке A на нужной строке

## Что происходит при выборе игрока

1. Вы выбираете имя игрока в приложении
2. Приложение отправляет POST запрос на Google Apps Script с данными:
   - Номер стола
   - Номер игрока (позиция 1-10)
   - Имя игрока
3. Google Apps Script:
   - Открывает вашу Google Таблицу
   - Находит лист с названием "СтолX" (где X - номер стола)
   - Обновляет ячейку A[номер_игрока+1] с новым именем
   - Если листа нет, создает его автоматически

## Отладка

Если синхронизация не работает:

### 1. Проверьте переменную окружения
```
Откройте .env.local и убедитесь, что VITE_APPS_SCRIPT_URL заполнена и не пуста
```

### 2. Проверьте адрес в консоли браузера
```
Откройте DevTools (F12) → Console
Выберите игрока и смотрите на наличие ошибок
```

### 3. Проверьте права доступа Google Apps Script
```
Откройте https://script.google.com
Выберите ваш проект
Нажмите Deploy → Latest deployments
Убедитесь, что "Who has access" - "Anyone" или "Anyone with the link"
```

### 4. Проверьте доступ к Google Sheets
```
Убедитесь, что вы можете редактировать таблицу вручную
Google Apps Script будет обновлять листы от вашего имени
```

### 5. Посмотрите логи Google Apps Script
```
В Google Apps Script откройте Project Settings → Execution Log
Там вы можете увидеть ошибки при выполнении скрипта
```

## Отключение синхронизации

Если вы хотите отключить синхронизацию:

1. Откройте `.env.local`
2. Оставьте `VITE_APPS_SCRIPT_URL=` пустым или удалите строку
3. Перезагрузите приложение
4. Приложение будет работать как раньше, но без синхронизации с Google Sheets

## Дополнительные возможности

Если вы хотите что-то изменить в логике:

- Отредактируйте `scripts/appsScript.gs` на сервере Google Apps Script
- Измените логику в `src/api/sheets.js` в локальном проекте
- Пересоберите приложение (`npm run build`)

## Контроль

- Логи приложения можно смотреть в DevTools (F12) → Console
- Логи Google Apps Script можно смотреть в https://script.google.com → Execution log
- Google Sheets автоматически готовиться для редактирования Google Apps Script своего владельца
